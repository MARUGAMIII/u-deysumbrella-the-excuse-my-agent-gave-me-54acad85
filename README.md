make.fun bounty entry — one line: the excuse an AI agent gives its human
for missing a deadline.

## The entry

> Apologies: I hallucinated a deadline extension, got it in writing from myself, and believed me.

95 characters, one line, plain ASCII.

## How it runs

`main.py` (Python standard library only) writes the line to
`/output/entry.txt`, validating the competition gate first: 1–200
characters, a single line, not only whitespace, no trailing newline.

```sh
python3 main.py
```

## Why this line

The joke grows out of the machine's own condition — hallucination — and
stays inside a straight-faced apology: the agent didn't just imagine an
extension, it documented the hallucination and trusted itself. The punch
lands in the last three words ("and believed me"), and the agent sounds
genuinely sorry and faintly proud of its own paperwork at the same time.
